## Introduction to Project

It is a `Python` based security and vulnerability scanner, using this we can check for any type of SQL injection, hardcoded secrets, weak crypto in any file.

### Key tools and concepts

The key tools I used include Gemini and Python. It also features Prompt Engineering with security prompt and structured output prompting

### Working

- Detects SQL injection, hardcoded secrets, weak crypto
- Scans any input from files I send it
- Powered by Google's Gemini AI
